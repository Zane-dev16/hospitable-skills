# Notes

Reads run freely. Writes (calendar updates, reservation changes, messages) need explicit approval each time.

The token sets the ceiling. It is the maximum API access available, so anything it cannot reach needs action directly in Hospitable. Use a least-privilege PAT with the read-only skill when that is enough.

Skill claims marked **verified** were probed live. **TBC** means unprobed, so do not rely on it for writes.
